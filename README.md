This project focuses on building an automated disease prediction system using machine learning techniques to analyze patient health data. The dataset was preprocessed through data cleaning, feature selection, and exploratory data analysis to improve model reliability. Supervised classification algorithms were trained and evaluated using performance metrics such as accuracy, precision, recall, and confusion matrix. The project demonstrates the application of Python and scikit-learn in healthcare analytics, highlighting how machine learning can support early disease detection and data-driven clinical decision-making.
